Job Description

三項核心任務

✏️ 標題設計（每日 1 份）

設計品牌核心貼文標題（10–15 字以內），避免強烈推銷感。

✓ 標題可搭配既有素材或簡易排版，無需高強度設計

💬 社群維護與互動

以溫和、禮貌且具品牌溫度的語氣回覆粉絲（Threads / Instagram / Facebook）。

✓ 有完整 FAQ 回話包，加上自己的風格即可

🔍 趨勢內容捕捉（每週 1 則）

蒐集符合品牌風格的內容靈感（排版風格、美食熱門話題），彙整至雲端文件並附簡短說明。
